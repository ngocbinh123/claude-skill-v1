# android-toolkit

Android native development skills for Claude Code.

| Skill | Triggers on | Teaches |
|---|---|---|
| `android-build-errors` | Gradle failures, sync errors, AGP/AAPT/manifest errors | First-`Caused by:` diagnosis, toolchain compatibility, dependency conflicts |

## Install

```
/plugin marketplace add ngocbinh123/claude-skill-v1
/plugin install android-toolkit@ngocbinh-skills
```

## Data handling

Plain-markdown skills: no external calls, no data collection, nothing
executed at install time.
