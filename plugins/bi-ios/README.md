# bi-ios

iOS native development skills for Claude Code.

| Skill | Triggers on | Teaches |
|---|---|---|
| `bi-ios-build-errors` | Xcode build failures, signing, pod install, SPM resolution | Five-bucket triage (signing / deps / compile / link / environment) with targeted fixes |

## Install

```
/plugin marketplace add ngocbinh123/claude-skill-v1
/plugin install bi-ios@bi-skills
```

## Data handling

Plain-markdown skills: no external calls, no data collection, nothing
executed at install time.
